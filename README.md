# 通用签到表生成器

一个**单文件、双击即用**的签到表批量生成工具。把人员名单（Excel/Word）和签到表模板（Word/Excel）交给它，它能自动完成判重、分类、逐人填写，一键输出整套 Word 签到表。

> 无需安装、无需联网、不依赖任何运行时——一个 exe 就是全部。

![预览效果](docs/images/07-预览.png)

## 功能特性

- **八步向导**：输入名单与模板 → 重复项核对 → 名单字段用途 → 字段对应关系 → 填写签到信息 → 预览 → 输出 → 分类输出
- **名单格式灵活**：Excel（.xlsx，多工作表可勾选参与）或 Word（.docx）表格均可作名单
- **模板格式灵活**：Word（.docx）或 Excel（.xlsx）模板均可，内置 12 个常用模板（培训/会议/活动 × 3 种风格 × 含经典表单版式）
- **自动判重**：按"姓名 + 班组 + 身份证号 + 手机号"（名单里有哪项比哪项）识别重复人员，可逐条改判
- **留空字段识别**：模板没有 `{占位符}` 也能用——"培训项目｜＿＿＿"这种"标签格＋空白格"自动识别为可填字段
- **逐人多列映射**：工号、岗位等名单字段可映射到模板数据区列，逐人填入
- **分类拆分**：按班组/部门等字段自动拆分成多份签到表，命名"标题-分类.docx"
- **分类归并**：如"维修组并入维修班"，小分类合并统计
- **排除人员**：如"序号 = 外派"的行不参与生成
- **容量自动拆分**：单张容量按模板自动检测（数据行 × 姓名列数），超员自动拆成多张
- **留空手写**：任何字段留空，输出文档对应位置留白，供打印后手写
- **不改动模板结构**：只往格子里写字，行列、合并单元格原样保留

## 快速开始

1. 双击 `通用签到表生成器.exe`（Windows 10 及以上，内嵌 WebView2 界面）
2. 上传名单、选择模板，按向导一步步走
3. 完成后逐张下载 Word，或打包下载全部 zip

详细图文教程见 **[操作手册](docs/操作手册.md)**。

## 从源码构建

```bash
# 需要 Go 1.22 及以上
go build -ldflags="-s -w -H windowsgui" -o 通用签到表生成器.exe .
```

- `-H windowsgui`：静默启动，不弹黑色控制台窗口
- 界面与内置模板通过 `go:embed` 打进 exe，无外部依赖文件
- 回归测试：`go build -o e2e.exe ./cmd/e2e && e2e.exe`

## 目录结构

```
signsheet/
├── main.go                  # 入口：HTTP 服务 + WebView2 窗口（jchv/go-webview2）
├── internal/
│   ├── tplengine/           # 模板解析：姓名列定位、容量检测、留空字段识别
│   ├── docx/                # OOXML 直析：合并单元格、多行写入、占位符替换
│   ├── generator/           # 生成器：逐人填写、分类拆分、容量切分
│   ├── preview/             # HTML 预览还原（列宽、合并格）
│   ├── roster/              # 名单读取（xlsx/docx 多表）
│   ├── server/              # HTTP 接口（会话隔离，默认端口 17877）
│   └── store/               # 模板库持久化
├── web/                     # 前端（原生 JS 八步向导，go:embed 内嵌）
├── builtins/                # 内置 12 模板（go:embed 内嵌）
├── cmd/
│   ├── e2e/                 # 端到端回归测试
│   └── mktemplates/         # 内置模板生成器
└── docs/                    # 操作手册与截图、演示数据
```

## 技术要点

- **纯 Go 直析 OOXML**：不走 Word COM，直接解析 `word/document.xml`，天然正确处理水平合并单元格（gridSpan）
- **WebView2 内嵌窗口**：关闭窗口即退出程序；WebView2 不可用时自动回退浏览器打开
- **本地运行**：所有数据只在本机内存与临时目录，不上传任何服务器
